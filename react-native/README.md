# CardBox POS - React Native (Expo) Edition

النسخة الكاملة لتطبيق **كارد بوكس لنقاط البيع (CardBox POS)** مبنية بتقنية **React Native + Expo**.

## 🚀 كيفية تشغيل المشروع على جوالك أو الكمبيوتر:

1. **انتقل لمجلد المشروع:**
   ```bash
   cd react-native
   ```

2. **تثبيت الحزم (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل تطبيق Expo:**
   ```bash
   npx expo start
   ```

4. **المعاينة والتشغيل:**
   - **على الجوال مباشرة:** حمّل تطبيق **Expo Go** من متجر Google Play أو App Store وامسح كود الـ QR الظاهر في الطرفية.
   - **في المتصفح:** اضغط حرف `w` في الطرفية ليفتح في المتصفح فوراً كـ Web App.
   - **على محاكي الأندرويد:** اضغط حرف `a`.
