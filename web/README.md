# CardBox POS Web Application (Vite + React + TypeScript + Tailwind CSS)

نسخة الويب الكاملة لتطبيق **كارد بوكس لنقاط البيع (CardBox POS)** المخصصة للتشغيل المباشر على الكمبيوتر أو المتصفح.

## 🚀 طريقة التشغيل على الكمبيوتر (Local Setup):

1. **افتح مجلد المشروع في سطر الأوامر (Terminal / PowerShell):**
   ```bash
   cd web
   ```

2. **تثبيت الحزم والمكتبات (Install Dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run Dev Server):**
   ```bash
   npm run dev
   ```

4. **افتح الرابط في المتصفح:**
   - سيفتح التطبيق تلقائياً على الرابط: `http://localhost:3000`

---

## 📦 بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
سيتم توليد ملفات الويب الجاهزة داخل مجلد `dist/` لرفعها على أي استضافة ويب أو سيرفر.

---

## 🌟 الميزات المضمنة في نسخة الويب:
- **لوحة تحكم نقاط البيع**: إحصائيات المبيعات والأرباح اليومية ورصيد المحفظة.
- **إدارة الشبكات المعتمدة**: متابعة السقف المالي، الأرصدة المتبقية، وطلب الانضمام لشبكات جديدة.
- **إصدار وطباعة كروت الإنترنت**: خصم مباشر من سقف الشبكة أو محفظة كارد بوكس وتوليد أكواد PIN و QR Code فورياً.
- **معاينة وطباعة الفواتير الحرارية**: متوافقة مع طابعات 58mm و 80mm وطباعة المتصفح.
- **تغذية المحفظة الإلكترونية**: دعم حساب الكريمي المميز، جوال باي، فلوسك، وون كاش.
- **سجل المبيعات والتقارير**: تصدير مباشر لملفات Excel / CSV.
- **حفظ البيانات محلياً (Offline Local Storage)**: الاحتفاظ بالبيانات والعمليات عند انقطاع الإنترنت.
