# 📱 تطبيق نقطة بيع كروت شبكات المايكروتك والإنترنت (POS System)

تطبيق أندرويد متكامل ومصمم بأسلوب حديث خصيصاً لأصحاب البقالات والمحلات التجارية ليكونوا **نقاط بيع معتمدة (POS)** لشبكات الإنترنت اللاسلكية وشبكات المايكروتك المحلية.

التطبيق مطور باستخدام أحدث تقنيات أندرويد (Kotlin + Jetpack Compose) ومتوافق 100% مع كافة سياسات ومتطلبات **Google Play Console (2025/2026)** بما فيها دعم Android 15/16 والتصميم حافة إلى حافة (Edge-to-Edge).

---

## 💡 معمارية النظام والربط مع السيرفر (System Architecture & API Integration)

يتصل التطبيق بنظام Backend API متكامل وسيرفرات شبكات المايكروتك لتوفير تجربة نقطة بيع لحظية وموثوقة:

## 🚀 سجل الإصلاحات والتحديثات الشاملة (Changelog & Technical Enhancements)

### 🔐 1. نظام التحقق وتغيير كلمة المرور بالحماية الثنائية (OTP & Account Security)
* **الربط الفعلي مع السيرفر لطلب رمز التحقق (SMS OTP Request):**
  - تم ربط عمليات تغيير وإعادة تعيين كلمة المرور وحذف الحساب مع السيرفر مباشرة عبر الـ Endpoints المخصصة (`/api/pos/password/forgot` و `/api/pos/password/reset`).
  - إظهار مؤشرات تحميل تفاعلية أثناء طلب الرمز لمنع النقر المزدوج والتكرار.
* **نافذة تحقق أمنية تفاعلية متطورة (Interactive 6-Digit PIN Modal):**
  - تصميم واجهة تحقق مخصصة بـ **6 مربعات رقمية مستقلة** مع تأثيرات بصرية عند التركيز، والتحكم التلقائي في مؤشر الكتابة.
  - دعم كامل للوحة المفاتيح الرقمية مع ضبط المسافات التلقائي لمنع حجب الحقول (`imePadding`).
* **عداد تنازلي ذكي لإعادة الإرسال (Countdown Timer Engine):**
  - إضافة عداد زمني (دقيقتين) لمنع الإرسال العشوائي، مع زر تفاعلي **"إعادة إرسال SMS"** ينشط تلقائياً فور انتهاء العداد.
* **إعادة التعيين المباشرة عند نسيان كلمة المرور:**
  - إمكانية إعادة تعيين كلمة المرور فورياً عبر رسالة SMS دون الحاجة لمعرفة كلمة المرور السابقة.
* **تحديث بيانات نقطة البيع:**
  - إمكانية تعديل وحفظ اسم المحل/المتجر والعنوان الجغرافي محلياً وفي السيرفر عبر زر الحفظ المباشر.
* **الحذف الآمن للحساب (Secure Account Deletion):**
  - نافذة تحذيرية مع اشتراط تأكيد رمز OTP لضمان عدم حذف الحساب بالخطأ.

### 🔍 2. محرك البحث والشراء من كافة الشبكات (Universal Network Store & Hybrid Engine)
* **البحث المباشر:** إمكانية البحث السريع عن أي شبكة بالاسم، كود الشبكة، أو المنطقة الجغرافية.
* **الشبكة المنضمة (Joined Network):**
  - تظهر بشارة **"معتمدة"** مع إمكانية استعراض متجر الكروت.
  - إمكانية تثبيت الشبكة (Pin) لتظهر في واجهة التطبيق الرئيسية للوصول السريع.
  - الشراء يخصم من السقف المالي المتاح، وفي حال نفاد السقف المالي يتم الخصم مباشرة وتلقائياً من رصيد المحفظة.
* **الشبكة غير المنضمة (Unjoined Network):**
  - تتيح الدخول المباشر لمتجر الكروت واستعراض الباقات والأسعار دون اشتراط الانضمام المسبق.
  - **الشراء المباشر للجميع:** طالما يمتلك المستخدم رصيداً في محفظته الإلكترونية، يستطيع تحديد الكميات وإتمام الشراء الفوري مع خصم القيمة مباشرة من رصيد المحفظة.

### 💳 3. متجر الكروت وتحليل المواصفات الذكي (Smart Specs Parser)
* **محرك الشراء المزدوج والذكي (Hybrid Purchase Flow):**
  1. **المسار الأول (الشبكات المعتمدة بالسقف المالي):** يخصم مبلغ العملية أولاً من السقف المالي المتاح الممنوح من مالك الشبكة.
  2. **المسار الثاني (المحفظة العامة / نفاد السقف / شبكات غير منضمة):** يتم تحويل الدفع فورياً ليخصم من رصيد المحفظة الرئيسي.
  3. **تغذية سريعة بنقرة واحدة:** إذا كان رصيد المحفظة والسقف غير كافيين، تظهر نافذة تنبيه فورية تتيح الانتقال السريع لشحن المحفظة برقم الإيداع والعودة لإتمام الشراء فوراً.
* **تحليل واستخراج بيانات الكرت الذكي (Smart Specs Parser):**
  - تم إصلاح مشكلة تداخل ونصوص الكروت بحيث يقوم التطبيق باستخراج مواصفات الكرت بدقة متناهية:
    1. **الحجم والسعة (`dataQuota`):** استخراج السعة بدقة (مثل: `350 ميجا` أو `1 جيجا`) وعرضها في خانة الحجم المخصصة.
    2. **المدة الزمنية (`duration`):** استخراج مدة عمل الكرت وصياغتها لغوياً بشكل سليم (مثل: `5 ساعات` أو `ساعتان` أو `24 ساعة`).
    3. **الصلاحية (`validity`):** استخراج مدة الصلاحية وتنسيقها بإضافة التمييز العربي المناسب (مثل: تحويل `5` إلى `5 أيام`).
* **تصميم بطاقة الكرت (Grid Card Design):**
  - جدول مواصفات متناسق بمربعات واضحة وفواصل ناعمة تمنع أي التفاف أو تداخل في النصوص.
  - إبراز اسم الفئة والسعر بعملة الريال مع عداد كميات تفاعلي `+` و `-` نشط ومتاح لكافة الشبكات.
  - شارة توفر الكروت (`متوفر`) وشارة `الأكثر طلباً`.

### 📊 4. محرك الإحصائيات والحسابات اللحظية (Real-Time Stats & Debt Calculation)
* **تحديث فوري لحظي (Zero-Delay Stats):**
  - تم إصلاح آلية احتساب الإحصائيات لتتحدث فورياً وبشكل مباشر بمجرد إتمام الشراء دون الحاجة لمغادرة الشاشة والعودة إليها.
* **القيم المحسوبة بدقة:**
  - **الرصيد المتاح:** يخصم منه سعر الكرت فورياً من السقف المالي `(currentBalance - totalCost)`.
  - **الكروت المباعة:** زيادة فورية في عداد الكروت المباعة وإجمالي المبيعات التراكمية.
  - **المستحق لمالك الشبكة (الآجل):** احتساب مباشر لفارق السقف المالي عن الرصيد المتبقي لإظهار المبلغ الدقيق الواجب تسليمه لصاحب الشبكة.

### 💰 5. تغذية رصيد المحفظة عبر المحافظ الإلكترونية (E-Wallet Top-Up Engine)
* **معايرة أسماء البنوك والمحافظ القياسية (`Bank Name Normalization`):**
  - تم حل مشكلة خطأ عدم العثور على الإيداع عبر مطابقة اسم البنك البرمجي القياسي المطلوب في الـ Backend:
    | المحفظة في الواجهة | المعرف البرمجي المرسل للسيرفر |
    | :--- | :--- |
    | محفظة جيب | `Jaib` |
    | بنك الكريمي (حاسب / ام كريمي) | `Kuraimi` |
    | محفظة جوالي | `Jawali` |
    | محفظة ون كاش | `One_cash` |
    | محفظة فلوسك | `Floosak` |
    | محفظة سبأ كاش | `Saba_cash` |
    | محفظة بايس | `Pyes` |
    | محفظة إيزي | `Easy` |
    | كاش | `Cash_wallet` |
    | جوال | `Jawwal` |

* **نظام المطابقة المالية الثلاثية الصارمة (`Triple Reconciliation Check`):**
  - **التحقق من صحة المبلغ:** يقوم التطبيق بمطابقة المبلغ المدخل من قبل المستخدم مع المبلغ الفعلي المعتمد في السيرفر والحوالة البنكية (`Math.abs(rechargeAmount - expectedAmount) < 1.0`).
  - في حال اختلاف المبلغ المدخل عن مبلغ الحوالة الفعلي، يرفض التطبيق العملية فوراً ويظهر تنبيهاً دقيقاً:
    > *«المبلغ المدخل (X ريال) غير مطابق لمبلغ الحوالة الفعلي بالسيرفر (Y ريال). يرجى تصحيح المبلغ والمحاولة مجدداً.»*
  - **التحقق من اسم المحفظة:** التأكد من تطابق المحفظة المختارة مع المحفظة المودع بها السند بالسيرفر.

* **توصية هامة لمعالجة الحالات الحدية في السيرفر (Backend Anti-Double Spending & Edge Case):**
  - تم توثيق الآلية المثلى للسيرفر: *عند إرسال طلب تغذية برقم مرجعي صحيح ومبلغ غير مطابق، يجب على السيرفر التحقق أولاً من تطابق المبلغ وإبقاء حالة السند معلّقة `pending` (عدم تحويلها إلى `used`) وإرجاع خطأ عدم تطابق المبلغ، حتى لا يفقد العميل حقه في إعادة إدخال المبلغ الصحيح.*

* **نظام إشعارات شريط حالة النظام (System Status Bar & Heads-Up Notifications):**
  - تم إنشاء قنوات إشعارات ذات أولوية قصوى (`IMPORTANCE_HIGH`) مع دعم التنبيه الضوئي والاهتزاز والشارات (`Badges`).
  - دعم كامل لصلاحية إشعارات أندرويد الحديثة (`POST_NOTIFICATIONS` على Android 13+ / Tiramisu).
  - إرسال إشعار بنكي فوري يظهر في شريط الحالة وستارة الإشعارات وشاشة القفل فور نجاح عملية التغذية أو الشراء.
  - إيقاف رسائل الـ Toast المكررة واستبدالها بشرائط تنبيه أنيقة مدمجة داخل التطبيق وفق معايير Material 3.

### 🛡️ 8. أمان وخصوصية التعبئة التلقائية لرموز التحقق (OTP Autofill Security & Threat Modeling)
* **كيف تعمل التعبئة التلقائية لأكواد التحقق في أندرويد؟**
  - يتم جلب الرمز من خلال واجهة النظام الرسمية المشفرة **Google SMS Retriever API / Android Autofill Framework**.
  - تطبيقك فقط (المطابق لتوقيع الشهادة الرقمية `Hash Signature` أو التطبيق النشط على الشاشة) هو من يُسمح له بقراءة الرسالة الخاصة به دون منح التطبيق إذن قراءة كافة رسائل الـ SMS الخاصة بالهاتف (`READ_SMS`).
* **هل يستطيع مخترق أو تطبيق آخر معرفة رمز التحقق؟**
  - **منع التدخل الخارجي (App Sandboxing):** تطبيقات أندرويد معزولة في بيئة حماية صارمة (Sandbox). لا يمكن لأي تطبيق آخر التلصص على ما يكتب في واجهة تطبيقك.
  - **ميزة One-Time Password:** رمز الـ OTP صالح للاستخدام لمرة واحدة فقط ولدقائق معدودة (2 دقيقة) ثم ينتهي تماماً ولا يمكن إعادة استخدامه.

### 💰 9. نظام مزامنة سجل عمليات المحفظة والمطابقة الشاملة (Universal Wallet History Sync & Reconciliation)
* **دعم كافة أشكال JSON لسجل العمليات من السيرفر:**
  - تم تحويل استجابة الـ API لجلب بيانات وسجل المحفظة (`/api/pos/wallet/balance`) إلى قراءة ديناميكية مرنة تدعم كافة التنسيقات والمفاتيح (`transactions`, `recent_transactions`, `history`, `recharges`, `data`).
  - استخراج ذكي للحقول المختلفة من السيرفر مثل (`recharge_id`, `transaction_id`, `ref_id`, `created_at`, `timestamp`).
* **تخزين محلي فوري ومزامنة سحابية (Offline-First Local Storage + Cloud Sync):**
  - يتم حفظ عمليات الإيداع والتغذية المكتملة في قاعدة بيانات `Room` المحلية فور إتمام العملية بنجاح.
  - المزامنة التلقائية مع السيرفر عند سحب الشاشة للتحديث أو الدخول لشاشة المحفظة دون حذف أو إخفاء العمليات السابقة.
* **إصلاح قيود الفلترة وإلغاء التكرار (Smart Deduplication):**
  - تم ربط معرفات الطلبات وعمليات شراء الكروت بالرقم المرجعي المشترك (`referenceNumber` و `order.id` و `tx-cb-{order.id}`).
  - تم حل مشكلة ظهور شراء الكرت مرتين في سجل المحفظة من خلال منع إدراج العملية المكررة عند دمج جدول الحركات المالية `walletDao` مع جدول المبيعات `orderDao`.
* **إرشادات لمطور السيرفر حول استهلاك السندات (Backend Recommendation):**
  - يُوصى بعدم استهلاك السند أو الرقم المرجعي أو تحويل حالته إلى `used` إلا بعد اكتمال التحقق وتطابق المبلغ المدخل مع المبلغ المسجل بالسند، حتى لا يتم حرق السند في حال أخطأ العميل بكتابة المبلغ في المحاولة الأولى.
  - **حماية القنوات المشفرة (TLS 1.3 Encryption):** الاتصال بين التطبيق وسيرفر الـ API مشفر بالكامل ولا يمكن اعتراضه عبر الشبكة (MitM Protection).

## 🔌 دليل مسارات ونقاط الـ API في السيرفر (API Endpoints Reference)

| المسار (Endpoint) | الطريقة (Method) | الوظيفة والبيانات المرسلة / المستقبلة |
| :--- | :--- | :--- |
| `/api/pos/login` | `POST` | تسجيل دخول نقطة البيع وتوليد Bearer Token |
| `/api/pos/register` | `POST` | إنشاء حساب جديد لنقطة بيع وتوثيق الجوال |
| `/api/pos/password/forgot` | `POST` | إرسال رمز التحقق OTP عبر SMS للهاتف |
| `/api/pos/password/reset` | `POST` | التحقق من OTP وتعيين كلمة المرور الجديدة |
| `/api/pos/password/change` | `POST` | تغيير كلمة المرور بالتحقق من الحالية |
| `/api/pos/profile/update` | `POST` | تحديث اسم نقطة البيع والعنوان الجغرافي |
| `/api/pos/account/delete` | `POST` | حذف حساب نقطة البيع نهائياً بعد التحقق |
| `/api/pos/networks` | `GET` | جلب كافة الشبكات المتاحة مع حالة الانضمام والسقف المالي |
| `/api/pos/network/{id}/packages` | `GET` | جلب باقات وكروت شبكة معينة ومواصفاتها |
| `/api/pos/network/{id}/join` | `POST` | إرسال طلب انضمام لشبكة جديدة |
| `/api/pos/vouchers/generate` | `POST` | شراء وتوليد كروت المايكروتك وإرجاع رموز الكروت |
| `/api/pos/wallet` | `GET` | جلب بيانات المحفظة والرصيد الكلي والسقف المالي |
| `/api/pos/wallet/recharge` | `POST` | شحن وتغذية المحفظة آلياً برقم العملية واسم البنك |
| `/api/pos/orders` | `GET` | جلب سجل المبيعات والعمليات السابقة |

  - تفاصيل الباقة (السعر، السعة، المدة، الصلاحية).
  - باركود / QR Code للاتصال السريع بالشبكة.
